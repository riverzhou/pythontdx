## 三、写文档的约定

1. **编号是稳定 ID，不复用、不重排。** 新文档取下一个空号，标题写成 `NN · 名称`，
   并登记到本页对应分类里。已有的 `README.md` / 外部链接都靠编号定位。
2. **一篇文档只回答一类问题。** 指南写「怎么做」，架构写「为什么这样」，协议写
   「字段与证据」。混在一起时拆开，别让后来的人读完整篇才知道重点。
3. **结论必须有证据。** 协议字段写来源（官方文档/源码/真实报文 + 日期），
   性能写实测数字，未验证的标「未验证」。
4. **历史条目不改写。** 发布记录、踩坑、验收快照按当时的事实留在原处；
   路径变了就在文首加一句「路径说明」，不回去改历史正文。
5. **中文标题 + 短横线文件名。** 文件名用编号开头，避免改标题时连锁改链接。
