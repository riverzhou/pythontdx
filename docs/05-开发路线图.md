## 学习路径建议

这个项目本身就是一条从易到难的学习曲线：

| 阶段 | 你在练什么                                                      | 对应代码                                  |
| ---- | --------------------------------------------------------------- | ----------------------------------------- |
| 1    | Electron 三进程模型、IPC 两种模式                               | `src/main/ipc.ts`、`src/preload/index.ts` |
| 2    | 安全模型（contextIsolation / CSP / 白名单）                     | `window.ts`、`index.html`                 |
| 3    | TypeScript 类型契约设计                                         | `src/shared/**`                           |
| 4    | 网络编程（编码、超时、重试、缓存、并发控制）                     | `python/tdx_bridge.py`（1.5.0 起缓存/合并只在 Python） |
| 5    | 数据解析与容错（真实世界的脏数据）                              | `python/tdx_bridge.py` + `python/test_tdx.py` |
| 6    | 定时器与资源生命周期管理                                        | `services/poller.ts`、`services/tdx/bridge.ts` |
| 7    | SolidJS 响应式核心（signal / memo / effect / store / resource） | `stores/**`、`components/ChartPanel.tsx`  |
| 8    | SVG 数据可视化（坐标映射、路径生成、交互）                      | `components/TrendChart.tsx`               |
| 9    | CSS 设计系统与令牌化                                            | `styles/tokens.css`                       |
| 10   | 桌面应用工程化（打包、图标、自动更新）                          | `electron-builder.yml`                    |

**建议的学习节奏**：不要一次读完所有代码。
挑一个功能（比如「把分时图改成支持五日」），沿着数据流从渲染层往上读到主进程，
读完再自己动手加一遍。这样每一轮都会把整条链路走通一次。
