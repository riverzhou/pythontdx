# pythontdx 1.8.0：技术债清算 + 信息密度

本版不新增行情品类，重点是把 1.7.0 留下的代码级技术债还清，并在不牺牲可读性的
前提下，让同一块屏幕显示更多有效行情信息。

## 同屏密度

- 标题栏 44 → 38px、状态栏 28 → 24px、行情头约 148 → 104px；
- 图表二级工具（复权/均线/BOLL/线性/画线/副图）默认收起，点「工具」展开；
- 1440×900 主图高度约 525 → 610px；排行榜同屏 16 → 18 行；
- 默认栏宽 280/330 → 264/300（旧默认自动迁移），图表横向更宽；
- 排行榜、板块、选股、全市场、龙虎榜、异动、大盘资料、组合表统一紧凑行高；
- 行情头新增 PE/PB/流通市值/总市值估值行，字段缺失时自动隐藏；
- 1024×700 隐藏底部缩放提示，横轴时间刻度不再被遮挡。

## 技术债清算

- **TD21 面板推送下沉 Python**：新增 `python/push_manager.py` 与 `/api/push` SSE。
  渲染层不再持有面板 Timer，断线按稳定 id 重连；行情与面板推送共用同一套数据服务。
- **TD23 备份进度**：新增 `/api/progress` SSE，`DataPanel` 恢复真实字节进度。
- **TD10**：`pauseWhenHidden` 真正暂停行情订阅，状态栏显示「已暂停」。
- **TD11**：迷你走势首屏 20 只、滚动按可见行补、每分钟静默刷新最多 40 只。
- **TD13/TD19**：分时缩放/平移与 K 线 tail 合并规则复核，补统一测试向量。
- **TD22**：参考项目/依赖许可证核对并登记到 `docs/08`。
- TD5/6/7/8/9/12/14/15/16 移入「已接受的外部约束」，理由见 `PLAN.md` 第五节。

## 升级注意

- 旧默认栏宽 280/330 会自动迁移到 264/300；手动拖过栏宽的用户保持自己的值。
- 面板推送改为 SSE 后，桌面与 Web 均需更新到同一份 `out/web` 与 `tdx-bridge`，
  不要混用 1.7.0 渲染层与 1.8.0 后端。
- 版本号已升到 1.8.0；本轮只提交源码与验证，不自动打 tag/发布安装包。
