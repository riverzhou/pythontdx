# 发布说明

每个版本一份，文件名就是版本号（`2.0.1.md`）。

**约定**

- 这里只放「这一个版本对用户说了什么」：新功能、修复、产物、验证结果。
- 逐条变更汇总在 [`../../CHANGELOG.md`](../../CHANGELOG.md)；发布流程见
  [`../07-手动编译发布手册.md`](../07-手动编译发布手册.md)。
- 每次发布的过程存档（产物、实测数字、踩坑与修法）在 [`编年史.md`](编年史.md)，
  节号沿用原 `docs/07` 的第八~五十节。
- 发布工作流按版本号取文件：`.github/workflows/release.yml` 读 `docs/releases/<版本>.md`。
  发版前先写这一份，再打 tag。
