# pythontdx 2.0.1

**2026-11-14 · 发布后审计补丁：截图工具时序 + Wayland 文档**

2.0.0 发布后的全量复查发现两处需要收尾：截图工具的点击时序会让 README 的部分截图拍成
默认行情页；Linux 默认 Wayland 的行为没有写进 README。2.0.1 只修这些，不动业务功能。

## 修复

- **截图命令引号缺失**：采集命令里 `PYTHONTDX_CAPTURE_CLICK=$click` 没有加引号，
  含空格的选择器列表被 shell 拆开，`env` 只拿到第一个选择器——只打开了「+」菜单、
  没点条目，README 的「多股同列 / 全市场 / 排行榜 / 板块」四张截图因此变成默认行情页。
  命令已全部加引号，并用「当前激活标签页」逐张核对后重拍。
- **采集驱动加固**：`PYTHONTDX_CAPTURE_CLICK` 每个目标先轮询等待出现（最多 4 秒）
  再点击，未出现时打印警告。

## 文档

- README 新增「Linux 图形后端（默认 Wayland）」：默认参数、`PYTHONTDX_GRAPHICS`
  的 wayland/x11/vulkan 覆盖、托盘与窗口位置在 Wayland 下的边界。
- 全部截图按 2.0.1 重拍（1920×1080），最低档 1440×900 与 Web 各一张；
  发布说明与编年史补记本轮审计。
- `docs/25` 增加第三轮审计记录（Web/Electron 一致性 + 截图回归）。
