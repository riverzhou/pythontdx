# pythontdx 2.0.5

**2026-11-18 · 左栏三张列表统一：一套行组件、一套列宽、一条取价路径**

自选股 / 板块成分股 / 自定义板块原本是两套行组件、两套样式、两条取价通道。结果是同一个
左栏里板块行的字号更大、留白更多，名称被挤成「生益…」；板块的行情又走自己那套
「按 120 只一批、每秒拉快照」的通道，一旦那批请求失败或落在半路，板块列表就只剩名字，
而自选 / 自定义照常刷新。2.0.4 把三张列表收成一份实现，只动展示层与取价编排，
不动协议、缓存与数据湖。

## 修复

- **板块列表名称截断**：左栏 224px 时名称列只剩 37px（4 个汉字要 52px），实测
  「生益科技」显示成「生益…」。统一后同一宽度下名称列 81px，四个汉字任何档位都不截断。
- **板块列表只有名字没有价格**：板块成分股并入 `createQuoteStream` 的订阅集合，
  与自选 / 自定义同一份行情；实测「通达信88」88 行全部有价格。
- **切换页签整列横向跳一下**：自选几行（不出滚动条）、板块上百行（出 10px 滚动条），
  同一栏宽下行宽差 10px。`.sidebar__list` 加 `scrollbar-gutter: stable` 永久预留槽位。
- **价格列随数字长短漂移**：「3,587.83」比「201.19」宽，原来 `minmax(58px, auto)` 会让
  列宽随内容变，名称列跟着变。改成 `minmax(66px, auto)`，列位置固定。
- **三张列表都没有迷你图**：窄栏阈值 250px 恰好等于用户栏宽，三张列表全被收起。
  现在任何栏宽都保留迷你图：> 228px 用 46px、≤ 228px 用 26px。
- **迷你图缩水、右侧一段死白**：46px 被压到 26px，行尾还留着 20px 删除位占位。
  改回 46px，并去掉占位列 —— 自选删除按钮压在迷你图列上（悬停出现），价格列距行尾 8px。

## 变更

- **一个行组件**：`components/atoms/StockRow.tsx` 同时服务三张列表，差异只靠 props
  （`groupId`+`index` 可拖拽、`onRemove` 出删除按钮、`flash` 价格闪烁）；删掉
  `WatchRow.tsx` 与全部 `.sector-row*` 样式，行内布局只在 `layout/shell.css` 改一次。
- **一条取价路径**：删掉 `Sidebar` 里的 `loadSectorQuotes` / `refreshSectorQuotes`
  与「加载成分股行情」提示，板块代码并入 `App.quoteCodes()`。
- **设置项改名**：「自选股迷你走势」→「列表迷你走势」（三张列表都生效）。
