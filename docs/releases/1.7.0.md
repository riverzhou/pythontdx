# pythontdx 1.7.0 · 通讯协议统一 + 主窗口化

> 发布候选说明（2026-11-14）。实际发布前仍需重新打 Python 服务单文件、构建三平台包并实测。

## 一句话

Electron 和浏览器现在走**同一条本地 HTTP/WebSocket 数据协议**；行情相关的显示
全部进入主工作区标签页，只有设置/数据/F10 等少数工具保留弹窗。

![主界面](docs/assets/pythontdx-1.7-overview.png)

## 1. 通讯协议完全统一

- Electron 主进程只做四件事：窗口/托盘/更新、拉起本地 Python 服务、
  文件对话框、本机状态文件；
- 窗口加载 `http://127.0.0.1:<端口>`，和浏览器请求同一批 `/api/*`、同一条 `/ws`；
- 删除 `src/main/ipc.ts`、`QuotePoller`、`PushHub`、`src/main/services/tdx/**`、
  `src/web/http-api.ts`；
- 新增 `shared/desktop.ts` + `window.desktop`，只暴露浏览器做不到的壳能力；
- 参考 QuantV5：它的 Electron 同样只是本地 HTTP 页面 + 极薄 preload。

## 2. 主窗口化

行情相关页面全部变成工作区标签：

排行榜 · 板块/概念 · 全部 A 股 · 多股同列 · 条件选股 · 自选行情墙 ·
逐笔明细 · 复盘 · 组合分析 · 预警 · 龙虎榜 · 沪深异动 · 大盘资料

非行情标签自动收起右栏；关闭标签回到上一页；行情标签固定不可关。

保留弹窗：设置、数据工具、F10、公告、公式、指标、行情服务器、快捷键。

## 3. 通达信操作习惯

- 顶部：报价 / 分析 / 资讯 / 数据 / 工具；
- F3 上证、F4 深证、F5 分时↔日 K、F6 行情、F7 公告、F9 选股、F10 资料；
- 数字命令 60 排行榜、63 全部 A 股、77 龙虎榜；
- 搜索提交/自选点击回到行情标签；
- 逐笔“放大”改为主区「逐笔明细」标签；独立 K 线窗口、板块全屏选择层移除。
