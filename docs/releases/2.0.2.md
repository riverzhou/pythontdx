# pythontdx 2.0.2

**2026-11-14 · 图表头收拢：工具常驻一行、更新时间去掉、按钮间距统一**

2.0.1 之后收到的界面意见集中在两处：图表卡片头（展开「工具」时同屏出现两个更新时间、
工具本身还要单独占一行、更新时间的位置难看、按钮间距 10 / 8 / 8 三种混排）和行情头的
指标排（字太小、颜色没生效、拉成 12 等分格散得太开，放大后指数还会折行）。
2.0.2 把这些一起收口，只动展示层，不动行情、缓存与数据逻辑。

## 修复

- **图表头重复显示更新时间**：收起式二级工具行与标题区各渲染一个 `更新 hh:mm:ss`，
  展开工具行后同屏出现两个相同时间（DOM 探针实测两个 `.chart-live-badge`，文本一致）。

## 变更

- **工具常驻标题行**：删掉「工具」开关与整条二级工具栏，复权 / 均线 / BOLL / 线性 / 画线 /
  清除区间直接排在「指标 / 公式 / 复盘」那一行。分时 / 五日没有工具，空容器自动隐藏，
  不留空档；图表头从「展开时 3 行」变成固定 2 行。
- **更新时间不再常驻**：行情头已有「行情 / 接收」时间、状态栏也有实时时间，
  「最近推送 + 刷新间隔」改挂到刷新按钮的 `title`，悬停可见。
- **从左往右排**：工具贴行左缘，指标 / 公式 / 复盘 / 置顶 / 导出 / 刷新成组靠右。
- **间距统一**：组内 4px、组间 12px，复权分段控件右侧多 8px。
- **行情头指标排更好读**：今开 / 最高 / 最低 / 昨收 / 换手 / 量比 / 振幅 / 均价 / 涨停 /
  跌停 / 成交量 / 成交额字号 12px → 16px（标签 11px），不再拉成 12 等分网格，
  改为按内容宽度 + 固定 24px 列间距；窗口 ≤1660px 时字号仍保持 16px、只把列间距收到
  10px，保证深证成指这类 5 位数在 1440×900 下也只占一行；颜色按语义给全——今开 / 最高 / 最低 / 均价以昨收为基准（跳空低开时
  最高价也是绿、跳空高开时最低价也是红），涨停红、跌停绿，换手 / 量比 / 振幅 / 成交量 /
  成交额保持中性（没有涨跌方向）。顺带修掉 `.up/.down` 被 `.metric__value` 覆盖、
  指标一直只有白色的问题。
