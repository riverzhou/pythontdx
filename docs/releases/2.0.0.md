# pythontdx 2.0.0

**2026-11-14 · 界面改版收尾：副图入口回归 + 2.0 版本线**

1.8.0 发布后复查发现「副图指标」选择器被折叠进默认收起的图表工具行，用户无法在 K 线页
切换 MACD / KDJ 等副图。2.0.0 修复该入口，并把这次界面改版正式收口到 2.0 版本线。

## 修复

- **副图指标入口不可见**：MACD / KDJ / RSI / WR / CCI / BIAS / DMI / OBV / ROC / PSY /
  VR / CR / BBI / DMA / TRIX / SAR 选择器移回图表主工具栏（「扩展」右侧），
  任何 K 线周期都直接可见，切换即时生效并写入设置。
- **改版入口复查**：`+` 菜单 12 项、6 个弹窗、7 个标题栏工具、右栏 5 个页签，
  以及 F3~F10、60/63/77、`/`、`R`、`T`、`?` 快捷键全部在位，未发现其它入口丢失。

## 2.0 版本线包含（1.8.0 起）

- 三层导航：左栏「导航」（快捷页 + 视图切换）/ 右上角工具（含导航栏开关、全屏）/
  标签栏「+」完整页面目录；`+` 菜单视口夹取、收窄到 150px。
- 默认最大化启动、还原 1440×900；最小分辨率 1440×900，老存档一次性迁移。
- 逐笔明细整页：全天多列 + 自动滚屏 + 红买/绿卖/紫竞价/灰盘后 + 成交量分档。
- 表格：表头 sticky、名称列定宽、走势列右留白 2px 全表一致、1920 数据列自动放宽；
  1440×900 下 14 个列表窗口无横向滚动。
- 公告与 F10 同宽（1056px）、指标面板两列等距行、「+」菜单按内容收窄。
- Electron 与 Web 同一套 `/api` + `/ws`，Python 为唯一数据面；
  服务端面板推送 `/api/push`、备份进度 `/api/progress`、K 线增量缓存。
- Web/Electron UI 一致性验收：标题栏工具、6 个弹窗、主题切换、控制台 0 报错；
  浏览器版备份/恢复按钮置灰并提示改用桌面端。
