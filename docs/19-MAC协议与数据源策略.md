# 19 · MAC 协议矩阵与数据源策略

> 结论先说：**MAC（0x12xx）不是 7709 的超集，不能全面替代老协议**。
> 它覆盖报价/K 线/分时/逐笔/竞价/板块/资金流/异动等行情类能力，但**没有**
> 代码表、F10 文本、136B 财务、股本变迁、特殊涨跌停、退市日线、服务器文件、
> 九榜排行。正确做法是 **MAC 优先 + 7709 兜底**，并按数据集选择数据源。
>
> 实现：`python/tdx_mac.py`（原有 5 条）+ `python/tdx_mac_ext.py`（本轮 6 条）；
> 证据：`python/tests/test_mac_ext.py` + 2026-11-04 实盘探针。

## 1. MAC 是什么

MAC 是通达信客户端在 **同一个 7709 端口**上的一套「扩展请求」协议：

- 帧头 `0x1c`（客户端请求）/ 16 字节响应头，zlib 压缩；
- 三步握手（`0c021893...`、`0c021894...`、`0c031899...`）；
- 请求 = `0x1c 帧头 + u16 命令字 + 负载`，命令字 `0x12xx`；
- 与 7709 共用地址池，但**是另一套命令空间与字段布局**，不是「新版本 7709」，
  也不是「7709 的加密层」。

因此不能把 7709 的请求直接发到 MAC 命令上，也不能假设 MAC 有等价命令。

## 3. 为什么不能全面替代 7709

| 能力 | 7709 | MAC | 结论 |
| --- | --- | --- | --- |
| 代码表（0x044d/044e） | ✅ | ❌ | 7709 必需 |
| F10 文本（0x02cf/02d0） | ✅ | ❌ | 7709 必需 |
| 136B 财务（0x0010） | ✅ | ❌ | 7709 必需 |
| 股本变迁（0x000f） | ✅ | ❌ | 7709 必需 |
| 特殊涨跌停（0x0452） | ✅ | ❌ | 7709 必需 |
| 退市日线（0x052b） | ✅ | ❌ | 7709 必需 |
| 九榜排行（0x053f） | ✅ | ❌ | 7709 必需 |
| 服务器文件（0x06b9） | ✅ | △ 文件命令不同 | 7709 已够 |
| 报价 | ✅ 0x053e/054c/0547 | ✅ 0x122B | MAC 可优先 |
| K 线 | ✅ 0x052d | ✅ 0x122E | MAC 可优先 |
| 当日分时 | ✅ 0x0537 | ✅ 0x122D/123E | MAC 可优先 |
| 多日分时 | △ 5×0x0fb4 | ✅ 0x123E 一次 | MAC 更优 |
| 竞价 | ✅ 0x056a | ✅ 0x123D | 可按需 |
| 逐笔 | ✅ 0x0fc5/0fc6 | ✅ 0x122F | 已有回退 |
| 板块/异动/资金流 | ✅/MAC | ✅ | 已有 |

**结论**：MAC 能覆盖「行情类」的大部分，但 F10/财务/代码表/衍生数据仍在 7709，
所以不能全面采用；采用「按数据集选择 + 自动回退」。

## 4. 落地方式

### 4.1 离线同步的数据源

```bash
python offline_sync.py --preset daily --source auto   # 默认：K线/当日分时 MAC 优先，失败回退 7709
python offline_sync.py --datasets kline --source mac  # 只用 MAC（失败即任务失败）
python offline_sync.py --datasets kline --source 7709 # 只用主站
```

- `kline`：`mac_full_kline`（0x122E 分页，首根保留并标 `preCloseMissing`）
  失败回退 `full_kline`（0x052d）。
- `today_minute`：`mac_minute_archive_save`（0x123E 当日）失败回退 0x0537。
- 其他数据集仍走 7709/7615（MAC 无对应命令或字段不等价）。
- 桌面面板新增「数据源」下拉（自动 / 仅 MAC / 仅 7709）。

### 4.2 已验证的字段口径

- MAC K 线：36B/条，首条只作昨收基准；日期 u32 + 当日秒数；开高低收/额/量
  均为 f32；首根保留时 `preClose` 取上一页收盘（首页为 0，标 `preCloseMissing`）。
- MAC 分时：14B/点（分钟偏移/价/均价/量/保留），分钟标签整体后移 1 分钟；
  多日按分钟回绕切日；`days` 参数裁剪。
- MAC 竞价：16B/条（秒/价/已撮合/未撮合），未撮合为 `i32`，负数表示卖方。
- MAC 服务端信息：87B 起，4 段交易时段（9:30–11:30、13:00–15:00 等）。
- MAC 股票摘要：194B 定长，字段偏移见 `tdx_mac_ext.parse_symbol_info`。

## 5. 边界与后续

- 0x1217 是唯一未完全验证的 A 股相关命令：元信息 0x1215 正常，分片接口在测试
  主机返回 0 字节；生产文件下载继续用 0x06b9。
- 0x254D/0x2562 属 EX 通道，不做。
- MAC 长连接串行，不并发；离线同步的并发靠「多进程 × 每线程独立 MAC 连接」。
- MAC 解析只信任实盘报文验证过的偏移；未验证字段不写入 schema（保留原始值需
  后续单独设计）。
