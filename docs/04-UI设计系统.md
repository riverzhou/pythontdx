# 04 · UI 设计系统

> 全部样式集中在 4 个 CSS 文件里，顺序为：
> `tokens.css`（变量）→ `base.css`（重置）→ `components.css`（通用件）→ `panels/*`（业务面板）→ `layout/*`（骨架）。
> **想整体换肤，只改 `tokens.css` 一个文件。**
>
> 桌面与 Web 共用这套令牌与组件；差异只允许出现在窗口外壳。
> 操作习惯（快捷键、右键菜单、盘口点选、图表光标）以通达信官方客户端为参照，
> 见 `docs/00` 第 6.1 节。

## 一、设计原则

1. **信息密度优先，但不拥挤。**
   行情软件的价值在于「一屏看尽」，所以用 12–13px 的小字号、紧凑的行高，
   但靠**分组留白**和**卡片边界**把信息切成可扫读的块。
2. **动效只服务于反馈，不服务于炫技。**
   价格跳变闪一下（700ms）、卡片入场浮起一次、hover 有 120ms 的过渡——
   除此之外不加任何动画。
3. **数字必须等宽。**
   所有数字用 `font-variant-numeric: tabular-nums` + 数字专用字体，
   否则价格每秒刷新时整行宽度会来回抖动，非常廉价。
4. **颜色即语义。**
   红 = 涨，绿 = 跌，灰 = 平。这三个颜色在图标、边框、背景、图表里含义完全一致，
   靠 `toneOf()` 一个函数统一判定，绝不各写各的。

## 二、设计令牌

### 颜色

| 令牌                                                            | 深色主题                          | 用途                        |
| --------------------------------------------------------------- | --------------------------------- | --------------------------- |
| `--bg-base`                                                     | `#07090e`                         | 根背景色                    |
| `--bg-aurora`                                                   | 三层径向渐变                      | 极光背景，让纯色不「死黑」  |
| `--panel`                                                       | `rgba(255,255,255,.032)`          | 卡片/控件的玻璃底           |
| `--panel-hover`                                                 | `rgba(255,255,255,.055)`          | hover 态                    |
| `--panel-active`                                                | `rgba(91,140,255,.14)`            | 选中态                      |
| `--border`                                                      | `rgba(255,255,255,.072)`          | 常规描边                    |
| `--border-strong`                                               | `rgba(255,255,255,.14)`           | 强调描边（弹出层）          |
| `--text-1 / 2 / 3`                                              | `#e9edf7 / #96a1b9 / #5f6a82`     | 主 / 次 / 弱文本            |
| `--accent` / `--accent-2`                                       | `#5b8cff` / `#a06bff`             | 品牌渐变（`--accent-grad`） |
| `--up` / `--down` / `--flat`                                    | `#ff5470` / `#14c98c` / `#8b95ad` | 涨 / 跌 / 平                |

浅色主题在 `:root[data-theme='light']` 下整体覆盖同名变量，
**业务样式一行都不用改**——这就是令牌化的收益。

### 形状与间距

| 令牌                                         | 值                      | 用在哪                               |
| -------------------------------------------- | ----------------------- | ------------------------------------ |
| `--r-xs` `--r-sm` `--r-md` `--r-lg` `--r-xl` | 6 / 9 / 12 / 16 / 22 px | 标签 / 按钮 / 列表项 / 卡片 / 大容器 |
| `--sp-1` … `--sp-8`                          | 4 8 12 16 20 24 32 px   | 4 的倍数栅格                         |
| `--titlebar-h` `--statusbar-h` `--sidebar-w` | 46 / 30 / 272 px        | 三段式布局的三个关键尺寸             |

### 动效

| 令牌              | 值                          | 说明                     |
| ----------------- | --------------------------- | ------------------------ |
| `--ease`          | `cubic-bezier(.22,1,.36,1)` | 主缓动（出场快、落定慢） |
| `--dur-1 / 2 / 3` | 120 / 200 / 320 ms          | 反馈 / 状态切换 / 入场   |

`@media (prefers-reduced-motion: reduce)` 下全部压到 1ms——尊重系统的无障碍设置。

## 三、排版

```css
--font-ui:
  'Segoe UI Variable Text', 'Segoe UI', system-ui, -apple-system, 'PingFang SC',
  'Microsoft YaHei UI', 'Noto Sans SC', sans-serif;
--font-num:
  'Bahnschrift', 'DIN Alternate', 'Segoe UI Variable Display', 'Segoe UI', ui-monospace,
  'Cascadia Mono', monospace;
```

- 界面用系统 UI 字体，**不加载任何网络字体**（桌面应用不应该因为字体没下完而闪烁）；
- 数字用 `Bahnschrift`（Windows 自带的 DIN 风格可变字体）/ `DIN Alternate`（macOS），
  字面窄、字形硬朗，是金融终端的标准味道；
- 字号阶梯：`11 / 12 / 13 / 14 / 16 / 20 / 28 / 42`。最大那个 42px 只给主价格用。

## 四、关键视觉手法

### 1. 极光背景 + 玻璃拟态

```css
body {
  background-color: var(--bg-base);
  background-image: var(--bg-aurora); /* 三层径向渐变 */
  background-attachment: fixed;
}
.card {
  background: var(--panel);
  border: 1px solid var(--border);
  backdrop-filter: blur(20px) saturate(140%);
}
```

纯黑背景会显得「廉价且空」。三层低透明度的蓝紫色径向渐变叠在近黑底色上，
再让卡片用 `backdrop-filter` 把背景虚化透出来，就得到了有纵深的层次感。
`saturate(140%)` 让透出来的颜色更通透，是玻璃拟态的关键调味。

### 2. 数字跳动闪烁

```css
@keyframes flash-up {
  from {
    background-color: var(--up-soft);
  }
  to {
    background-color: transparent;
  }
}
@keyframes flash-down {
  from {
    background-color: var(--down-soft);
  }
  to {
    background-color: transparent;
  }
}
```

由 `createValueFlash()` 这个组合式函数驱动：
监听价格信号，数值变化时给出 700ms 的 `'up' | 'down'` 方向信号，然后自动复位。
实现要点是**每次变化前先清掉上一个定时器**，否则连续跳动会互相打断。

### 3. 涨跌色的多层用法

同一个 `--up` 红，有四种用法，形成完整的视觉语言：

| 场景         | 用法                                         |
| ------------ | -------------------------------------------- |
| 价格文字     | `color: var(--up)`                           |
| 选中/标签底  | `background: var(--up-soft)`（14% 透明度）   |
| 盘口挂单量条 | `background: var(--up-soft)`，宽度按占比生长 |
| 图表成交量柱 | `fill: var(--up)` + `opacity: .55`           |

### 4. 自绘标题栏

窗口 `frame: false`，标题栏自己画。两个必须知道的点：

```css
.titlebar {
  -webkit-app-region: drag;
} /* 空白处可拖动窗口 */
.titlebar__actions {
  -webkit-app-region: no-drag;
} /* 按钮必须退出拖拽区，否则点不动 */
```

macOS 上保留原生红绿灯（`titleBarStyle: 'hiddenInset'`），
并用 `:root[data-platform='darwin'] .titlebar { padding-left: 84px }` 给它让位。

### 5. 三栏一屏布局（没有任何滚动条）

这是本项目布局上最重要的一条约束：**默认窗口尺寸下必须一屏看尽，不出现滚动条。**

```
grid-template-columns: var(--sidebar-w) minmax(0, 1fr) var(--rail-w);
grid-template-rows:    var(--titlebar-h) minmax(0, 1fr) var(--statusbar-h);
```

做法不是「内容多了就滚动」，而是让每一块都具备收缩能力：

| 做法                | 说明                                                                  |
| ------------------- | --------------------------------------------------------------------- |
| 高度锁死            | `.app { height: 100%; overflow: hidden }`，任何一层都不许撑破视口     |
| 只有图表吸收余量    | `.chart-card { flex: 1 1 auto; min-height: 0 }`，其余部件都是内容高度 |
| 盘口行按比例均分    | `.ob-row { flex: 1 1 0; min-height: 18px }`，窗口变矮时行一起变矮     |
| SVG 不设 min-height | 图表高度完全由容器决定，`ResizeObserver` 实时测量后按真实像素重绘     |
| 空状态列自动收起    | `无选中股票时 .app--empty 把右栏宽度压成 0`，空间让给插画             |

窗口变窄时用媒体查询收紧两侧栏，把宽度让给图表：

```css
@media (max-width: 1240px) {
  :root {
    --sidebar-w: 224px;
    --rail-w: 282px;
  }
}
```

**验证方式**：`npm run shot` 截图后肉眼确认。滚动条这种东西，
类型检查和单元测试永远抓不到，只能看。

## 五、图表设计决策

图表是纯手绘 SVG（`TrendChart.tsx` / `KLineChart.tsx`），几个刻意的选择：

| 决策                                               | 理由                                                            |
| -------------------------------------------------- | --------------------------------------------------------------- |
| **按真实像素绘制**，用 `ResizeObserver` 量容器尺寸 | 用 `viewBox` 缩放会把线宽和文字一起拉伸变形，字会糊             |
| 分时横轴**固定 240 格**，盘中只画到当前时刻        | 专业分时图就是右侧留白的，拉伸铺满会让人误判走势节奏            |
| 纵轴以**昨收为中心上下对称**                       | 一眼看出当前偏离基准多少，而不是被最高最低价带偏                |
| 右轴同时给**价格和涨跌幅**两套刻度                 | 不同价位的股票可以横向比较                                      |
| 刻度步长自动在 `0.5% / 1% / 2% / 5% / 10%` 间切换  | 波动 0.8% 的股票也能看清细节                                    |
| K 线均线用「好看的数字」算法取刻度                 | `niceStep()`：1 / 2 / 5 × 10ⁿ，避免 `1234.5678` 这种刻度        |
| 十字光标用 SVG 画、浮层用 HTML 画                  | 线的位置要精确到像素；文字用 HTML 渲染质量更好、还能用 CSS 变量 |

### 五种图表形态

| 形态           | 构图要点                                                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **分时**       | 一天 241 个点铺在 240 格横轴上；纵轴以昨收对称；右轴给价格 + 涨跌幅双刻度                                                                     |
| **五日**       | 五天各占 241 格横向排开；**每一天单独一条折线、按当天涨跌上色**；纵轴改成真实价格区间（五日没有统一基准，画涨跌幅会误导）；交易日之间画分隔线 |
| **日/周/月 K** | 蜡烛 + MA5/10/20 + 成交量；纵轴用 `niceStep()` 取整刻度                                                                                       |
| **成交量柱**   | 颜色跟随该分钟的涨跌方向，透明度 0.55，避免喧宾夺主                                                                                           |
| **迷你走势图** | 46×22 px，只有一条折线 + 一层 14% 的填充；**不画坐标轴、不画网格、不画光标**——它在列表里，任何多余元素都是噪音                                |

### 十字光标读数联动

鼠标在图上移动时，图表标题区的图例会被替换成光标位置的读数
（时间 / 价格 / 涨跌幅 / 均价 / 成交量），移开后又变回图例——这是专业行情软件的标配。

实现上有一个容易写错的地方：**不要在图表组件里用 `createMemo` 做「通知外部」这件事**，
它是派生值的语义，不是副作用钩子。正确写法是：

```ts
createEffect(
  on(hovered, (current) => {
    props.onHover?.(current ? { ... } : null)
  })
)
```

## 六、无障碍与细节

- **焦点环**：`:focus-visible` 才显示轮廓，鼠标点击不显示——键盘用户看得见，鼠标用户不被打扰。
- **滚动条**：`background-clip: content-box` + 透明边框，做出「悬浮细条」的效果。
- **禁用文本选中**：`body { user-select: none }`，桌面应用不该有网页那种「一拖全蓝」的手感；
  需要复制的地方（如将来的代码块）加 `.selectable` 类。
- **语义化标签**：`<header>` / `<aside>` / `<main>` / `<footer>` 直接对应四块布局，
  屏幕阅读器和 DevTools 都更好读。
- **`title` 属性做补充说明**：关键指标（换手率、振幅、量比）都带 `title` 解释算法。

## 七、想继续美化，可以动这些地方

1. **主题色**：改 `--accent` / `--accent-2` 两个值，整站配色立刻换风格（推荐试试青色系 `#22d3ee`）。
2. **极光背景**：调 `--bg-aurora` 里三个径向渐变的圆心位置与透明度。
3. **玻璃强度**：`backdrop-filter: blur(20px)` 的数值，越大越朦胧（性能开销也越大）。
4. **圆角性格**：把 `--r-*` 整体调大 → 更柔和；调小 → 更硬朗专业。
5. **涨跌配色**：本项目只做 A 股，固定**红涨绿跌**；不要为港美股加绿涨红跌分支（超出范围）。
