## 二、方法（可重复）

1. **静态检查**：`tsc`（两套 tsconfig）、`eslint`、`python -m unittest`；
   另外用只读脚本扫描：`TODO/FIXME`、`any`、`@ts-ignore`、`innerHTML`、`eval`、
   `shell=True`、缺 `encoding=` 的 `open()`、`.only`、被吞掉的异常。
2. **契约比对**：从 `python/tdx_server.py` 抽出全部 `/api/*` 路由，从
   `src/renderer/src/lib/http-api.ts` 抽出全部客户端调用（含模板字符串），做双向差集。
3. **运行时验证**：`npm run shot`（Electron 生产页面）、`npm run shot:web`
   （`tdx_server --web-dir out/web` 单端口）、关键接口 curl 冒烟。
4. **文档核对**：文档里引用的仓库路径是否存在；数字型断言（命令数、数据集数、
   测试数、TTL）与代码常量/实测比对；截图引用与 `docs/assets` 对齐。

- **类型与规范**：`tsc` 两套配置、eslint 全绿；`src` 内 `any` = 0、`@ts-ignore` = 0；

## 七、如何重跑

```bash
npm run check                     # 类型 + Lint + 359 TS + 343 Python
npm run audit:docs                # 文档链接/截图/路径引用 + HTTP 契约
npm run build && npm run shot     # 桌面：构建 + 截图
python python/tdx_server.py --port 8765 --web-dir out/web &
npm run shot:web                  # Web 单端口截图（需要上面的服务）
npm run audit:data                # 数据覆盖自检（39 项，需要行情网络）
```

`npm run audit:docs` 覆盖第 2 节的文档核对与契约比对：
Markdown 相对链接、`docs/assets` 截图、反引号里的仓库路径（历史/外部路径有白名单）、
以及「客户端调用的 `/api/*` 必须都在服务端有路由」。改文档或加路由后跑一次即可。

## 八、第二轮：Web / Electron 一致性与发布前回归（2026-11-14 下午）

在 1.8.0 界面迭代（导航三层、逐笔整页、列宽/表头、全屏按钮、默认最大化）之后，
用「同一份 DOM 探针 + 同一份截图」对两端做了对照，并跑完整回归后打 tag 发版。

### 8.1 方法

- Electron 当浏览器加载 `out/web`（`--web-dir`），与桌面端执行同一段探针脚本；
- 探针覆盖：标题栏工具数、窗口按钮、左栏标题/快捷页/视图、`+` 菜单项与宽度、
  全市场表格行数/走势/sticky/溢出、6 个弹窗的开关、主题切换、localStorage 键、控制台错误；
- 桌面端用 `PYTHONTDX_CAPTURE_EVAL` 跑同一段逻辑，比对数值。

### 8.2 发现与修复

| ID | 级别 | 问题 | 修复 |
| --- | --- | --- | --- |
| W1 | P2 | 行情服务器弹层没有 `role="dialog"` / `aria-modal`，与其它弹窗不一致，自动化也定位不到 | 补 `role="dialog" aria-modal="true"` |
| W2 | P2 | 浏览器版「备份到… / 选择路径 / 选择备份」点击后才报「不能读写本机文件」 | 浏览器版直接置灰 + 标题提示 + 区块内强调色说明；数据湖/导出仍在浏览器可用 |

### 8.3 结果（两端一致）

标题栏工具 6 个；左栏「导航」+6 快捷页+3 视图；`+` 菜单 12 项/3 分组/150px 且在视口内；
全部 A 股 200 行、迷你走势渲染、表头 sticky、横向溢出 0；数据/设置/服务器/快捷键/F10/公告
6 个弹窗均可开关；深浅主题切换生效；两端控制台 0 错误；Web 端 localStorage 3 个键。

有意保留的差异见 `docs/22` §4.4（窗口按钮、F11 语义、浏览器通知、备份/恢复能力）。
