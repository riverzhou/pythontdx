# 13 · 技术分析算法（Python / TS 边界）

> 目标：智能画线不仅服务界面，也能直接用于数据挖掘、回测和机器学习。
> 算法归 Python，交互归 TS，避免两边各写一套。

## 1. 分层

```text
python/patterns.py
  摆动点、主摆动段、平行通道、斐波那契、测量、箭头、支撑压力
  纯函数；输入 bars，输出日期锚定的 plans
        ↓ chart_patterns（IPC / HTTP）
src/shared/patterns.ts
  稳定结果类型
        ↓
src/renderer/src/components/charts/KLineChart.tsx
  日期 → 当前图下标
  渲染、拖动、命中、撤销、持久化
```

## 2. Python 输入/输出

输入是普通 bar 列表（与 K 线缓存字段一致）：

```python
from patterns import build_smart_drawings, pattern_summary

plans = build_smart_drawings(bars, lookback=160)
summary = pattern_summary(plans)
```

计划字段：

| 字段                      | 含义                                                   |
| ------------------------- | ------------------------------------------------------ |
| `type`                    | `fib` / `measure` / `arrow` / `channel` / `horizontal` |
| `startDate` / `endDate`   | 日期锚点                                               |
| `startPrice` / `endPrice` | 起止价格                                               |
| `price`                   | 水平线价格                                             |
| `offset`                  | 通道垂直价差                                           |
| `algorithm`               | `swing-combo-v1`                                       |
| `score`                   | 当前固定基线分，后续可换模型                           |

日期锚定是刻意设计：历史数据前插、复权变化、前端窗口变化都不会让线错位。

## 3. 接口

Python 桥接命令：

```json
{
  "cmd": "chart_patterns",
  "payload": { "code": "sh688499", "period": "day", "adjust": "qfq", "lookback": 160 }
}
```

HTTP：

```text
POST /api/chart_patterns
```

返回：

```json
{
  "code": "sh688499",
  "period": "day",
  "source": "cache",
  "summary": {"algorithm": "swing-combo-v1", "count": 4, "types": ["..."], "generatedAt": "..."},
  "plans": [...]
}
```

## 4. 机器学习/回测复用

Python 端不依赖 Electron/TS，可直接遍历数据湖：

```python
from patterns import build_smart_drawings

for code_dir in lake.glob("cache/klines/*_day_all_qfq.parquet"):
    bars = read_bars(code_dir)["bars"]
    plans = build_smart_drawings(bars)
    # 写入 pattern 表 / 生成特征 / 按日期回放
```

建议后续扩展：

- `algorithmVersion` 参与数据分区/去重；
- 每条 plan 保存 `score`、`params` 和源 bars 的 `sha256`；
- 先做离线批量重算，再做前端在线提示；
- 不在 TS 里复制摆动/通道算法。

## 5. 边界

- TS 只做日期→下标、像素坐标、拖动与渲染；
- Python 不做屏幕坐标；
- 算法版本升级时必须新增版本号，不覆盖旧版本语义。
